# Throttle Quest v1.0 — Launch Edition

Open `index.html` in Chrome or host the folder on GitHub Pages.

## Focus of this build
This version is intended as the first student-facing playtest build. It keeps the paid-upgrade economy, career structure, garage, questions, and 20 courses from v0.9, while polishing the first impression and overall presentation.

## New in v1.0
- New Home / title screen with launch presentation, rider crew, next-goal prompt, and collection preview.
- Shop now feels more like a dealership, with a featured bike panel and high-level collection stats.
- New collection book in Records showing manufacturer-by-manufacturer ownership progress.
- Stronger presentation language and a more student-facing “launch edition” flow.
- Existing tutorial, garage, educational question system, championships, and learning reports retained.

## Notes
- This remains an offline browser game with local saves.
- Prices and performance remain game-balanced estimates.
- Art is still stylized procedural vector art rather than custom hand-drawn sprites for every model.
- Chromebook performance should still be checked in the real classroom.
